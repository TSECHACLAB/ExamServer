# Issue #36: 「分からない」回答状態

## 目的

演習中に選択肢を選べない問題でも、受験者が意図的に「分からない」と記録して先へ進めるようにする。これは問題データの選択肢ではなく、受験セッション中の回答状態として扱う。

## 非ゴール

- 問題 JSON、スキーマ、正解データは変更しない。
- 採点ルールや部分点計算は変更しない。
- 「見直したい」フラグとは統合しない。

## 状態遷移

| 現在状態 | 操作 | 次の状態 | 備考 |
| --- | --- | --- | --- |
| 未回答 | 「分からない」を押す | dontKnow | 選択肢は `null` のまま |
| 回答済み | 「分からない」を押す | dontKnow | 選択済みの選択肢を解除する |
| dontKnow | 「分からない」を押す | 未回答 | トグルで解除する |
| dontKnow | 選択肢を選ぶ | 回答済み | dontKnow を解除する |
| フラグあり | 「分からない」を押す | フラグあり + dontKnow | フラグは直交状態として保持する |
| dontKnow + フラグあり | フラグを押す | dontKnow | dontKnow は保持する |

## 採点と結果表示

- 本番モードでは `dontKnow` の回答は未回答と同じく `answer: null` として採点する。
- スコア計算上は未操作の未回答と同一に扱う。
- 結果画面では、回答状態が渡っている場合に限り「未操作」と「分からない」をリスト上のマークで区別する。
- 一問一答モードでは、「分からない」を押すと未回答のまま正解・解説を表示する。

## 保存互換

- 進行中セッションの保存データに `dontKnow` を含める。
- 旧データに `dontKnow` がない場合は `false` として読む。
- 旧実装名 `uncertain` が残っている保存データは、読み込み時だけ `dontKnow` へ正規化する。
