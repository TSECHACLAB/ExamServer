# 問題データと公式公開範囲の監査

- 実施日: 2026-08-06（解説品質の全件再監査: 2026-08-07）
- 対象: 演習カテゴリの問題本文、正答、出典、重複、解説、図表
- 判定基準: 試験実施団体の公開ページと配布資料を一次資料とする

## 結論

SGは、IPAが一般公開している実試験問題を全て演習化した。対象は、令和5〜8年度の公開問題60問と、平成28年度春期〜令和元年度秋期の午前400問・午後24大問257解答欄である。

公式資料上の正答717件は、同一内容の再出題47件と、同じ設問を解答欄ごとに繰り返していた午後10画面を統合し、660問に整理した。削除した出題回と解答欄は捨てず、各問題の出題履歴と複数選択の正答集合として保持している。

ここでいう「全て」は、IPAが公開している範囲を指す。令和2〜4年度のSG問題はIPAが非公開としているため収録対象外である。公式サンプル63問、出典不明の転載、記憶再現問題、exam dumpも本番プールへ入れていない。

## 重複の扱い

午前は、Unicode、空白、句読点、選択肢順を正規化した完全一致に加え、文字3-gramの類似度が高い候補と、語句差が大きい再出題候補を個別に確認した。

- 候補460問を413問へ統合
- 重複グループ44件
- 削除した重複出題47件
- 高類似候補18組、意味上の再出題13組を確認
- 似ているが問いが異なる1組は別問題のまま保持

午後は、同じ設問文と選択肢を解答欄ごとに複製せず、本来の「二つ選べ」「三つ選べ」という一問へ戻した。

- 複数選択へ戻した設問8件
- 対応する公式解答欄18件
- 削除した重複画面10件
- 選択上限は正答数と一致させ、解答欄単位で部分点を計算

### 解説品質の全件再監査

2026-08-07に、現行公開問題60問、旧午前353問、旧午後247問の計660問を再監査した。正答記号だけでなく、設問固有の判断根拠、主要な誤答を分ける条件、計算過程、午後の空欄と本文の対応、複数正答の全要素を確認した。

- 決定的検査: 正答見出し、誤答の正答扱い、内部資料の露出、本文の完全一致流用を660問全てに実施。指摘0
- 独立レビュー: ローカルの`gpt-oss:20b`で660問全てを評価。最終結果は合格660、指摘0、未判定0
- 修正: 現行4問、旧午前4問、旧午後2問の計10問。解説本文の流用3組、正答と説明の矛盾、職務分離の取り違え、ライセンス条件の矛盾、ビット条件の曖昧さ、図表型組合せの説明不足を解消
- 手動再判定: 独立レビューが公式図を読めなかった3問と、日本語の選択肢記号「エ」を英字Eと誤読した1問を、公式画像又は正答監査記録で再判定。4件とも入力ハッシュと証拠ハッシュを固定し、内容変更時は無効になる

説明を長くすること自体は品質基準にしていない。正答を選べる決め手が既に明確な解説は維持し、確認できた問題だけを設問固有の文章へ直した。異なる問題で解説本文が完全一致した場合は、午前・午後の生成処理と回帰テストの両方で失敗する。

## 配信と採点

- 受験前APIは`answer`、`explanation`、重複元の正答位置、解答PDF、採点講評PDF、文書ハッシュを返さない。
- 解答後だけ、正答・解説・IPAの問題PDFへの出典リンクを表示する。
- 重複統合した問題は、主出典だけでなく全ての出題年度と問番号を表示する。
- 年度・期を複数選んだとき、共通する重複問題を二重に数えない。

## 証拠の限界

旧SGの公式問題PDFは文字情報を持たない画像PDFである。正答列、PDFハッシュ、図表、問番号、歴史的用語は原本と照合したが、全本文の文字単位OCR一致を証明するものではない。本文の転記には第三者サイトを補助利用し、出典としては採用していない。スキーマ検証は、問題数、正答、出典対応、画像参照、重複、解説の形式崩れを継続的に検知する。
